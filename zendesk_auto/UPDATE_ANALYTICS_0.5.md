# 토큰·정확도 관리 업데이트 0.5

기존 Claude 추천 전용 앱에 적용합니다. 실제 Zendesk 티켓 수정 기능은 추가되지 않습니다.

## 토큰 탭

Claude 호출에 대해 모델, 목적(가상 테스트/실제 티켓), 시각, 프롬프트 버전, 응답의 입력·출력 토큰과 캐시 토큰을 로컬 기록으로 저장합니다. 200 응답이 오더라도 거부/잘못된 형식이면 받은 사용량을 기록합니다. 오류나 응답 유실로 사용량을 받지 못한 호출은 미확인으로 집계합니다. API 미설정으로 호출하지 않은 경우는 호출이 아닙니다.

집계는 업데이트 이후 호출만 포함하며 과거 사용량이나 실제 결제 금액을 소급하지 않습니다. 캐시 사용량은 응답 값 그대로 별도로 보존하며 토큰 합계를 청구 금액으로 환산하지 않습니다. 가격/실제 결제액은 Claude 콘솔에서 확인하세요.

## 엑셀 비교

`토큰·정확도 > 완료 티켓 비교`에서 기존 개발팀 엑셀과 동일한 형식의 XLSX를 업로드합니다. 기존 검색용 History는 바꾸지 않으며 평가 목록에 티켓번호별 추가·갱신합니다. 여러 탭의 동일 번호는 합칩니다.

엑셀의 `개발담당자/PIS담당자` 열과 현재 등록된 개발자 이름을 비교해 담당자 후보를 표시합니다. 이 열은 실제 최종 해결자와 PIS가 섞였거나 복수 명일 수 있어 어떤 후보도 자동 정답으로 확정하지 않습니다. 추천 이력과 완료 상태를 확인할 수 있는 건에 한해 사용자가 최종 개발 담당자 및 사유를 확인한 뒤 정확도 분모에 넣습니다.

현재 지표는 확인한 표본의 **최초 추천 담당자와 확인된 최종 담당자의 일치율**입니다. 부재·업무량·정상 이관도 이름 불일치에는 포함되지만 오류 사유는 별도 집계하며 모델의 분류 오류로 사용하지 않습니다. 업무 분류가 틀린 경우 정정 파트를 등록합니다. 추천과 최종 담당자가 같더라도 파트가 다르면 분류 오류로 검토할 수 있습니다.

업데이트 이후에는 티켓별 추천 시점의 결과를 별도 이벤트로 저장해 최초 담당자 추천과 프롬프트 버전을 보존합니다. 업데이트 전에 만들어진 티켓은 현재 `data/state.json`에 남은 추천을 보조적으로 사용하며 버전과 최초 여부를 보장할 수 없습니다. 현재 결과가 덮여 있거나 지워졌다면 복원할 수 없어 `추천 이력 없음`으로 표시합니다. 가상 테스트는 실제 티켓으로 취급하지 않습니다.

## 프롬프트 개선

1. PIS가 검토한 건에서 `업무 분류 오류`를 선택하고 실제 정정 파트를 저장합니다.
2. `개선 후보 생성`을 누르면 확인된 오류 최대 8건을 요약해 버전이 있는 정정 참고 사례를 자동 구성합니다. 모델에 추가 생성 요청을 보내지 않습니다.
3. 후보를 펼쳐 내용을 검토한 후 `적용`을 누릅니다. 기존의 고정된 보안 지시문을 대체하지 않고 검증된 사례를 추가합니다. 실수로 적용한 경우 `기본 프롬프트로 복원`을 사용할 수 있습니다.
4. 적용 전후 성능은 개선에 사용하지 않은 별도 신규 사례로 검토하세요. 후보 생성만으로 정확도 개선이 입증되는 것은 아닙니다. 해당 티켓 자체를 다시 분석할 때 동일 티켓 정정 사례는 프롬프트에서 제외합니다.

검토 시 최신 결과가 아닌 최초 추천을 비교하며, 담당자 변경만으로 오류를 단정하지 않습니다. 사용자 검토가 잘못되면 개선 데이터도 잘못될 수 있으므로 개발팀·PIS가 판정해야 합니다.

## 저장과 보안

Google Sheets Settings에는 적용된 개선 버전과 정정 참고 사례가 들어갑니다. 상세 평가, 추천 이력, 사용량과 후보는 서버 `data/usage_events.json`, `data/decision_events.json`, `data/evaluation_cases.json`, `data/prompt_versions.json`에 저장합니다. DB 없이 기존 단일 서버 파일 저장 방식입니다. `data/`를 백업하지 않으면 새 기능의 이력을 복원할 수 없습니다. 파일에는 비식별화를 시도한 문의 요약이 포함되며 패턴 마스킹은 완전한 비식별화를 보장하지 않습니다. 접근 권한 및 회사 개인정보 정책을 확인하세요.

## 설치

기존 프로그램을 중지하고 아래를 실행합니다. ZIP은 앱 코드와 이 문서만 포함하며 `.env`, `data`, `secrets`, `.venv`, Google Sheets 자료를 덮어쓰지 않습니다.

```bash
cd ~/zendesk_auto/zendesk_auto
unzip -o Zendesk_Analytics_update_0.5.zip -d .
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8080 --workers 1
```

브라우저에서 Ctrl+F5 후 `토큰·정확도` 탭을 확인합니다. Claude, Google Sheets 및 Zendesk의 실제 연결은 사용자 환경에서 확인이 필요합니다. 자동 테스트는 모의 응답을 사용했습니다.
