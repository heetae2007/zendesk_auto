# Zendesk 422 수정 및 Telegram 형식 업데이트 0.6

이 패키지는 추천 전용 앱 업데이트입니다. 기존 Zendesk 읽기 검색에서 Search Export API의 필수 `filter[type]=ticket`을 별도 인수로 전달하도록 수정합니다. 신규 및 미해결 조회 양쪽에 적용합니다. 페이징 링크는 기존대로 사용합니다.

추천 결과 알림 형식:

```text
[부산부민] 진료지원 김정진 책임님 (담당자 추천)

심장초음파실 검사 건수가 워크리스트와 기능검사 시행 건수에서 달라 확인이 필요합니다.

티켓: #98018  ← 클릭하면 해당 Zendesk 티켓 열기
```

티켓번호는 Telegram 인라인 링크로 전송됩니다. 일반 메시지에는 `담당자 추천`, 검토 대상에는 `검토 필요`, 긴급 대상에는 `긴급 검토 필요`를 표시합니다. 실제 Zendesk 담당자를 변경하지 않으므로 추천임을 표시합니다. 병원명은 Zendesk 병원 필드와 설정된 병원 표시값 매핑을 사용하며 임의로 병원명을 줄이지 않습니다. 매핑하지 않았으면 API의 값이 표시되거나 병원 확인 필요로 표시됩니다.

가상 테스트는 `[테스트]`와 가상 티켓 표시가 붙으며 실제 티켓 링크는 없습니다. Telegram 전송은 결과를 받은 후에도 네트워크 장애로 응답이 유실될 수 있습니다. 이 경우 무분별한 중복 전송을 막기 위해 자동 재전송하지 않습니다.

기존 요청의 개인정보 보호 원칙에 따라 환자 이름/주민번호/진료기록을 포함한 원문을 Telegram으로 그대로 보내지 않고 Claude가 생성한 비식별 요약을 사용합니다. 패턴 마스킹과 AI 지시만으로 모든 개인정보 제거를 보장하지 못하므로 실제 운영 전 확인하세요. 요약문은 현재 350자까지 표시하며 원본 장문을 보존하는 기능은 아닙니다.

## 설치

이 ZIP은 `app` 코드와 이 설명만 포함합니다. 기존 `.env`, `data`, `.venv`, `secrets` 및 Google Sheets를 포함하거나 초기화하지 않습니다. 기존 프로그램 중지 후 ZIP을 프로젝트 폴더에 복사하고:

```bash
cd ~/zendesk_auto/zendesk_auto
unzip -o Zendesk_422_Telegram_update_0.6.zip -d .
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8080 --workers 1
```

웹 화면을 Ctrl+F5로 새로고침합니다. 기존 자동 수집 설정이 켜져 있으면 재실행 후 운영 시간에 미처리 신규 티켓을 읽고 Claude 분석·알림을 시도할 수 있습니다. 먼저 테스트하려면 자동 수집을 꺼두고 `추천 테스트`에서 가상 문의를 작성해 Telegram 테스트 전송을 선택하세요.

입력·출력 사용량과 검토 사례·추천 이력은 기존 서버 `data`에 남습니다. 실제 Zendesk·Claude·Telegram 연결은 제공자 계정에서 확인이 필요합니다.
