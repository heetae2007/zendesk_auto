# 이지엣지 0.9.3 — 밀린 티켓 배정 미리보기

0.8 이상의 기존 버전에 적용하는 테스트 업데이트입니다. 0.9~0.9.2의 PIS 배분 미리보기, 엑셀 업무 설정, 가상 테스트 PIS 선택을 포함합니다.

## 시험 방법

1. 세부업무 설정에서 엑셀을 읽고 내용을 확인한 후 저장합니다.
2. PIS 배분 미리보기에서 당일 실제 근무 중인 젠콜 담당자만 선택합니다. 부재자는 선택하지 않습니다.
3. 밀린 티켓 미리보기 입력란에 한 줄마다 `파트, 세부업무`를 입력합니다. 세부업무 설정에 저장된 이름과 정확히 일치해야 합니다.
4. 입력 순서에 따라 해당 업무의 PIS 주담당, 백업 순으로 확인하며, 선택된 젠콜 담당자만 배정합니다. 같은 미리보기 묶음에서는 같은 담당자에게 한 건만 배정합니다. 적격한 사람이 없거나 업무 기준이 없거나 중복되면 미배정입니다. 설정의 `한다연/조한슬`처럼 슬래시로 구분한 정확한 이름은 차례로 확인합니다.

이것은 가상 테스트이며 현재 Zendesk 실시간 티켓, 당일 젠콜 일정 또는 부재 정보를 자동 조회하지 않습니다. 기존 비율 배분 미리보기는 별도의 실시간 건당 배분 계산이며 밀린 티켓 규칙을 적용하지 않습니다. 실제 Zendesk 등록·스크린샷 인식·자동 PIS 선택·실제 Telegram의 PIS 자동 표시는 아직 구현되지 않았습니다.

## 설치

실행 중인 프로그램을 종료하고 ZIP을 프로젝트 폴더에 복사한 후:

```bash
cd ~/zendesk_auto/zendesk_auto
unzip -o EasyEdge_PIS_backlog_0.9.3.zip -d .
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8080 --workers 1
```

`.env`, `data/`, `secrets/`, `.venv`는 ZIP에 포함되지 않습니다. 기존 자동 수집이 활성화됐다면 재시작 후 실제 Zendesk 조회·Claude 호출·Telegram 알림이 다시 발생할 수 있습니다. 사내 공유에 별도 바인딩을 쓰는 경우 기존 설정을 유지하고, 웹에서 Ctrl+F5로 새로고침하세요.
