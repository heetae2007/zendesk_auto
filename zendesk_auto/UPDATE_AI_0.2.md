# AI 우선 추천 업데이트 0.2

기존 0.1 설치에 적용하는 추천 전용 업데이트입니다. Zendesk 티켓 쓰기/공개 답변 기능은 포함하지 않습니다.

## 변경 사항

- AI가 신규 문의를 먼저 분석하고, 결과를 구조화된 JSON으로 받아 요약·파트·근거를 기록합니다.
- 키워드 규칙은 추천에 참고하며, AI 결과와 충돌하면 검토 대상으로 전환합니다. AI 비활성·실패 시 규칙만으로 자동 추천하지 않습니다.
- 과거 완료 사례를 검색하며 임베딩 모델 미설정 시 문자 유사도 검색입니다. 의미 검색을 사용하려면 임베딩 모델을 설정해야 합니다.
- 날짜별 설정이 없는 파트는 그 파트의 활성 담당자 전체를 후보로 사용합니다. 특정 날짜 설정이 있으면 해당 날짜의 주담당·대체 담당이 우선합니다. 휴가자는 날짜별 설정에 근무 가능한 사람을 지정하거나 담당자를 비활성화하세요.
- Telegram에 AI가 생성한 요약, 추천 파트·담당자, 판단 근거, 티켓 링크를 표시합니다. 전송은 AI 활성화 및 Telegram 알림 활성화 후 이뤄집니다.
- 기존 .env, Google Sheets, data/, secrets/, .venv는 업데이트 ZIP에 포함되지 않습니다.

## 테스트 범위와 제한

pytest 30개로 AI 우선 호출, 규칙 충돌, 상시 후보, 요약 알림, 휴무일, 중복 실행, API 실패 등을 가짜 서비스로 검증했습니다. 실제 Zendesk, OpenAI, Telegram, Google Sheets 연결은 미검증입니다.

공휴일과 09:00~18:00 운영 시간 밖의 분석은 다음 운영 시간에 진행합니다. 긴급 판단은 후보이며 실시간 비상 시스템을 대체하지 않습니다. 과거 티켓 내용은 별도의 개인정보 검토 후 사용하세요.

개인정보 패턴 마스킹과 모델에 대한 비식별 지시를 적용했지만 자유 텍스트의 모든 개인정보 제거를 보장하지 못합니다. Telegram에 문의 요약과 판단 근거가 전달되므로 실제 운영 전 사내 보안 정책과 수신 대화방을 확인하세요.

실제 미해결 업무량은 Zendesk 필드·담당자 ID 매핑을 완료해야 정확합니다. 미설정 시 업무량이 0으로 표시될 수 있어 추천 우선순위는 참고용입니다.

## 서버 업데이트

1. 기존 프로그램을 Ctrl+C로 종료합니다.
2. 받은 ZIP을 서버에 복사합니다.
3. 프로젝트 경로에서 `unzip -o ~/Zendesk_AI_update_0.2.zip -d .`를 실행합니다. 이 ZIP은 `app/`의 네 파일과 이 문서만 교체합니다. `.env`나 데이터는 포함하지 않습니다.
4. `.env`에 OpenAI, Zendesk, Telegram 연결값을 입력하고 프로그램을 재시작합니다.
5. 웹의 연결 및 설정에서 외부 AI 분석, Telegram 알림, 자동 수집·추천을 각각 활성화합니다. AI 활성화 이후 API 사용료가 발생할 수 있습니다.

예시 .env (키를 채팅이나 화면에 공유하지 마세요):

    OPENAI_API_KEY=발급받은_API_키
    OPENAI_MODEL=gpt-4o-mini
    OPENAI_EMBEDDING_MODEL=
    ZENDESK_EMAIL=젠데스크_계정_이메일
    ZENDESK_API_TOKEN=젠데스크_API_토큰
    TELEGRAM_BOT_TOKEN=텔레그램_Bot_토큰
    TELEGRAM_CHAT_ID=텔레그램_대화방_ID

모델은 OpenAI API 프로젝트에서 사용할 수 있어야 합니다. `OPENAI_EMBEDDING_MODEL`을 비워두면 무료 의미 검색으로 바뀌는 것이 아니라 문자 유사도로 검색하고, AI 분류 API 호출 비용은 별도로 발생합니다.

한 번에 과거 미처리 신규 티켓을 분석할 수 있으므로 Zendesk 대상과 사용량을 살펴본 뒤 자동 수집을 켜세요. 3회 실패한 티켓은 검토 상태가 되며 다시 분석하려면 접수 현황의 재분석 버튼을 사용합니다.
